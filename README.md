# RoAmigos 🌍

### Travel. Connect. Remember.

RoAmigos is a travel discovery and social connection platform that helps people explore destinations worldwide, discover interesting places, connect with friends, and preserve their travel memories.

## Features
- Worldwide place discovery
- Interactive Google Maps
- Place search and autocomplete
- Connect with friends
- Chat and groups
- Personal trips and travel memories

## Technology Stack
- React
- TypeScript
- Firebase
- Google Maps Platform
- Google Places API

## About
Explore the world, connect with people, and create unforgettable memories with RoAmigos!
