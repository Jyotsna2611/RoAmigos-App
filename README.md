# 🌍 RoAmigos

### Travel. Connect. Remember. ✈️

RoAmigos is a travel and social discovery web application that helps people explore destinations, connect with friends, plan trips, and preserve their travel memories.

## 🚀 Live Demo

**[🌐 Explore RoAmigos](https://gen-lang-client-0052806592.web.app)**

## ✨ Features

- 🌍 **Discover Places** – Explore places and destinations around the world.
- 📍 **Interactive Maps** – Find locations using Google Maps.
- 🔎 **Smart Search** – Search destinations with autocomplete suggestions.
- 👥 **Connect with Friends** – Find and connect with other users.
- 💬 **Real-time Chat** – Communicate with friends.
- 🧳 **My Trips & Memories** – Create, manage, and save your travel experiences.
- 🔔 **Notifications** – Stay updated with app activities.
- 🔐 **Authentication** – Secure user login and registration using Firebase.

## 🎨 Design

**Theme:** Mint Explorer 🌿

A clean, modern interface with a soft pastel colour palette inspired by travel and exploration.

## 📌 Project Goal

RoAmigos aims to bring travel discovery and social connections together in one platform, making it easier to explore new places and create memories with friends.
